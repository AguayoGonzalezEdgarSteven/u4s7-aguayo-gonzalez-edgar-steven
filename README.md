## ✨ Mejoras implementadas

### 1. Paginación
Se incorporó la paginación para facilitar la navegación entre los elementos del listado.

### 2. Búsqueda
Se agregó una función de búsqueda simple para localizar servicios de manera más rápida.

### 3. Estados vacíos
Se implementaron mensajes informativos cuando no existen servicios registrados o cuando la búsqueda no devuelve resultados.

### 4. Accesibilidad
Se agregó el atributo `aria-label` al buscador para mejorar la accesibilidad de la interfaz.

### 5. Diseño responsivo
Se incorporó la clase `overflow-x-auto` para permitir el desplazamiento horizontal en dispositivos móviles cuando sea necesario.
